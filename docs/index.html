Every release, newest first. Download ooa-setup-VERSION.zip (Java included), unzip it and run Install.cmd. Install your license file in Administration > Licenses; without one, a new install runs a 30-day evaluation.

Check a download before installing: with an earlier install, run ooa release verify ooa-VERSION.manifest.json in the folder with the downloads (it checks the vendor's signature, then each file). Otherwise compare the SHA-256 below with certutil -hashfile FILE SHA256. The checksums here come from each release's signed manifest.
